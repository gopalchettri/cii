# architect: mitre-pipeline (19 Nov 2026)

See ADR-010. A separate run (`pipeline: "mitre"`): MITRE data first, the AI selects actors from all of them, plans paths over every technique and the ICS asset types, writes one scenario per path in parallel; code checks every ID. Shared `tsg_sessions` / `tsg_scenarios`; one new task `tsg_write_mitre_scenarios` on `tsg_scenarios`; two new collections `tsg_mitre_enterprise_stix` / `tsg_mitre_ics_stix` (`_id` = STIX id, index `by_version`), filled by the always-on import. Controls through the existing `tsg_map_controls` from `content.attack`. Layers as ADR-004: crud/mitre (repository), search/mitre (index), domain/scenario/mitre_scenario (engine, session), worker/scenario/mitre (task), api/routes/mitre_scenarios.py. No new ErrorCode (`GENERATION_FAILED`), no new ConflictReason (`SCENARIOS_NOT_REGENERABLE`).
